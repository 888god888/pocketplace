口袋收藏：自動整理與地圖更新

這是累積更新，包含先前的 IG 連線、多店收藏、Google 地圖和預設店名修正。只需使用這份最新 ZIP，不必依序上傳舊版。
檔案已準備好，但尚未上傳到你的 GitHub，線上網站需完成以下更新才會改變。

更新方式（原本使用 GitHub Actions 的網站）：
1. 解壓 pocketplace-auto-capture-update.zip。
2. 開啟 https://github.com/888god888/pocketplace ，按 Add file → Upload files。
3. 將 src、tests、ready-to-upload 資料夾及 README.md 拖入，保留資料夾結構，提交更新。
4. 等 Actions 的 Deploy GitHub Pages 完成，再重新開啟網站。
5. 如果仍顯示舊版，關閉這個網站的所有分頁後再開。不要清除網站資料，避免刪除本機收藏。

若 Pages 原本是 Deploy from a branch：
改為把 ready-to-upload「裡面的檔案」放到網站根目錄，包含 .nojekyll，使用其中的 index.html。兩種部署方式擇一。

更新後的流程：
貼上 IG 連結／貼文文字，或加入截圖 → 自動辨識與整理 → 自動附地圖搜尋 → 確認後按「收進口袋」。
多家店可一次勾選保存，截圖不必另外補原文網址。
已存在的預設名稱卡片：開啟 → 按「重新整理資訊」→ 確認店名 → 儲存修改。

地圖不需手動填：有地址以店名＋地址搜尋，否則以店名＋地區搜尋。
這是搜尋連結，尚未驗證商家或分店，不會自動抓評分、營業時間等資料。
若想指定分店才需要使用「指定地圖分店（選填）」。

不需要新增 AI／Google 金鑰，不需要改 Supabase、Secrets 或 JWT；使用你目前已設定好的 IG 連線即可。
辨識仍是 OCR 與文字規則，模糊畫面、沒有公開文字的內容可能無法完整整理。缺少的資訊會留白，保存前仍可修正。
首次 OCR 載入可能較久，畫面有進度與停止按鈕。
收藏仍存在各裝置瀏覽器，不會自動跨裝置同步；更新前可先使用完整備份匯出。

驗證：22 項測試與正式建置通過。已實際測試貼文字自動整理，以及上傳截圖 → 自動 OCR → 附地圖 → 收藏 → 重新整理後仍保留。
